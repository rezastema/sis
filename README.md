# Project Title

Student Information Systems (SIS)

## Framework

Django (Python)

## Database

SQLite 
PostgreSQL

## Description

Student Information System (SIS) adalah aplikasi berbasis web yang digunakan untuk mengelola data siswa dan mencatat kehadiran mereka. Sistem ini dirancang untuk membantu institusi pendidikan dalam menyimpan, mengelola, dan mengakses informasi dengan lebih efisien.
